# Student-Result-Management-System
The Student Result Management System is a Python-based GUI application developed using Tkinter, OpenPyXL, and Microsoft Excel. The main purpose of this project is to provide a simple and user friendly system for storing and managing student academic results. 
# Student Result Management System
A Python-based GUI application for managing student academic results.
# Features
- Add student results
- Update student information
- Delete student records
- Search student records
- Store results in Excel
- User-friendly GUI
## Technologies Used
- Python
- Tkinter
- OpenPyXL
- Microsoft Excel
